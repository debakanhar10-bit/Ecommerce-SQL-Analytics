# E-Commerce Sales & Customer Analytics

## 📌 Project Overview
This project analyzes e-commerce sales and customer data using MySQL to generate meaningful business insights.

## 🛠️ Tools Used
- MySQL
- SQL
- MySQL Workbench
- Git & GitHub

## 🔍 Analysis Performed
- Sales & Revenue Analysis
- Product Performance Analysis
- Customer Analysis
- Category Analysis
- Payment Mode Analysis
- Discount Analysis
- Monthly Sales Trends

## 💡 SQL Concepts Used
- SELECT & WHERE
- GROUP BY & HAVING
- JOINs
- CASE WHEN
- Subqueries
- CTEs
- ROW_NUMBER()
- RANK()
- DENSE_RANK()
- LAG()
- Window Functions

## 🎯 Business Insights
The project helps identify top-performing products, high-value customers, revenue trends, category performance, payment preferences, and discount impact.
